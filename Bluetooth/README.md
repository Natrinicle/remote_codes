# Bluetooth

Bluetooth protocol notes (GATT and classic SPP), grouped by device type.
Same type / brand / model tree as [Infrared](../Infrared/). These are
not Flipper `.ir` files.

Wired UART / HID / RS485 / CAN live under [Serial](../Serial/). LAN
collectors live under [Network](../Network/).

Helpers print payloads. They do not scan or GATT-connect. Label printers
also have a LAN IPP client under [Printers/label-bridge](Printers/label-bridge/).
