# Luxpower (BLE)

Luxpower LXP / SNA / ACS / GridBoss hybrids that connect over Bluetooth
LE. This is not Voltronic QPIGS and not SRNE Modbus `@256`.

No encoder in this folder until a unit is on the bench. Do not invent
GATT UUIDs.

USB UART notes: [Serial/Inverters/Luxpower](../../../Serial/Inverters/Luxpower/).
TCP notes: [Network/Inverters/Luxpower](../../../Network/Inverters/Luxpower/).

## Identification

| | |
|--|--|
| Models | LXP, SNA, ACS, GridBoss |
| Transport | BLE |

## Notes

- Own hardware only.
- BLE, UART, and TCP are different reaches of the same inverter family.
