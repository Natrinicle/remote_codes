# Scales (Network)

Wi-Fi body scales that provision over LAN multicast or a scale AP.
These folders are **product cards**. Provision shouts live under
[WiFi_Provision](../WiFi_Provision/). BLE GATT lives under
[Bluetooth](../../Bluetooth/). These folders are not Flipper `.ir` files.

Helpers print payloads. They do not bind UDP ports or send a live
SmartConfig shout.
