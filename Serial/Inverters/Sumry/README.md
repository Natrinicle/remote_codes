# Sumry (UART Frame8851)

Sumry HGX / hybrid / off-grid boxes on USB UART. Broker framing is labelled
Frame8851 on this family (not Voltronic QPIGS, not SRNE `@256`).

No encoder in this folder until a unit is on the bench. Identify by
rejecting QPIGS and Modbus FC3 `@256` before inventing bytes.

## Identification

| | |
|--|--|
| Transport | USB UART |
| Frame | Frame8851 |
| Models | HGX, hybrid, off-grid variants |
