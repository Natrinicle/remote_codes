# Inverters (Serial)

USB UART, USB HID, RS485, and CAN inverter families. LAN tunnels live
under [Network/Inverters](../../Network/Inverters/). BLE lives under
[Bluetooth/Inverters](../../Bluetooth/Inverters/).

| Brand | Transport | Path |
|-------|-----------|------|
| SRNE | USB UART Modbus RTU 9600 8N1 | [SRNE](SRNE/) |
| Voltronic | USB HID or UART ASCII PI30 | [Voltronic](Voltronic/) |
| GoodWe | USB UART Modbus fn 165 | [GoodWe](GoodWe/) |
| Midnite | CAN 29-bit | [Midnite](Midnite/) |
| Sumry | USB UART Frame8851 | [Sumry](Sumry/) |
| Luxpower | USB UART | [Luxpower](Luxpower/) |
