# BMS (Serial)

RS485 and USB UART battery monitors. JBD BLE `FF00` is the radio sibling of
[JBD](JBD/) UART (same `DD…77` bodies).

| Victron | VE.Direct 19200 8N1 | [Victron](Victron/) |
